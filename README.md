# ☁️ Cloud & IT Operations Analytics

An interactive data analytics project designed to monitor and analyze **cloud infrastructure and IT operations performance** using Python and Tableau.

The project focuses on analyzing infrastructure metrics such as CPU utilization, memory utilization, errors, incidents, availability, response time, network traffic, and server status across different regions and server types.

---

## 📊 Interactive Dashboard

Explore the fully interactive Tableau dashboard:

🔗 **[View Cloud & IT Operations Analytics Dashboard on Tableau Public](https://public.tableau.com/views/Cloud_IT_Administration/CloudITOperationsAnalyticsDashboard?:language=en-US&publish=yes&:display_count=n&:origin=viz_share_link)**

The dashboard includes interactive filters for:

- 🌍 Region
- 🖥️ Server Type
- 🚦 Server Status

These filters allow users to explore infrastructure performance from different perspectives.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Monitor cloud and IT infrastructure performance.
- Analyze CPU and memory utilization trends.
- Identify regions with higher error counts.
- Monitor total incidents and system errors.
- Evaluate infrastructure availability.
- Compare response times across server types.
- Analyze network traffic across regions.
- Understand server health and status distribution.
- Present operational metrics through an interactive dashboard.
